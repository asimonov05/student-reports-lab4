# Отчёт о тестировании

Дата проверки: 7 ноября 2026 года. Объект — Bash-программа анализа данных студентов. В Linux успешно пройдены 62 проверки вычислений; результаты на исходной базе сопоставлены с независимыми эталонами.

## Условия

Проверки выполнены в контейнере `os-lab4-qa:local` на Debian GNU/Linux 13 (trixie), архитектура aarch64. Версии: Bash 5.2.37, GNU awk 5.2.1, ShellCheck 0.10.0. Локаль — `C.utf8`.

Небольшая контролируемая база создаётся сценарием `tests/make-fixture.sh` во временном каталоге. Она включает две группы, два предмета, совпадающие имена в разных группах, кириллицу, двойную фамилию, неупорядоченные даты и оценки с суффиксами. Повреждённые варианты создаются в отдельных копиях. Исходная база преподавателя не редактируется.

Воспроизведение из корня проекта в Linux:

```bash
for script in bin/student-report lib/reports.sh tests/*.sh; do
    bash -n "$script"
done
shellcheck -x bin/student-report lib/reports.sh tests/*.sh
bash tests/test.sh
```

Проверки синтаксиса Bash и ShellCheck всего кода и тестов завершились без замечаний.
