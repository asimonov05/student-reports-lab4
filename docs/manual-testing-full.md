# Ручное тестирование CLI на базе ЛР № 3

Основной прогон — разделы 01–22; последний блок необязателен. Выполняй команды по порядку в одном терминале Bash из папки проекта. Все данные берутся из архива ЛР № 3; изменения выполняются только в отдельных копиях. Копируй команды вместе с комментариями для скриншотов.

## Подготовка

```bash
# Подготовка: распаковываем настоящую базу ЛР № 3. Нужны Bash 4+, gawk и unzip.
APP="$PWD/bin/student-report"
ARCHIVE="/home/psidjik/code/mpei/os-labs/labs-2026/lab3/labfiles-3-26.zip"
QA=$(mktemp -d)
unzip -q "$ARCHIVE" -d "$QA/source data"
DATA="$QA/source data/labfiles-3-26"
unset STUDENT_DATA_DIR

# Фиксируем версию программы, окружение и путь к базе для отчёта.
git rev-parse --short HEAD
bash --version | head -n 1
gawk --version | head -n 1
printf 'База ЛР 3: %s\nМатериалы проверки: %s\n' "$DATA" "$QA"

# Сохраняем суммы ДО запусков: затем проверим, что база не изменилась.
find "$DATA" -type f -exec sha256sum {} + | LC_ALL=C sort > "$QA/before.sha256"
wc -l "$QA/before.sha256"
# Ожидается: 119 файлов. При ошибках подготовки дальше не переходить.
```
