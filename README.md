# Анализ данных студентов

Лабораторная работа № 4: пять отчётов о посещаемости и результатах тестов на данных файловой системы преподавателя из ЛР № 3. Программа работает в Linux; обработка реализована на Bash и GNU awk, графический интерфейс на русском языке — через Zenity.

## Установка и запуск

Нужны Bash 4 или новее, GNU awk (`gawk`), стандартные утилиты Linux и локаль UTF-8. Для графического интерфейса дополнительно нужны Zenity и работающая графическая сессия Linux.

Для Debian или Ubuntu:

```bash
sudo apt-get update
sudo apt-get install bash gawk zenity
git clone https://github.com/asimonov05/student-reports-lab4.git
cd student-reports-lab4
./bin/student-gui
```

Репозиторий закрытый: для клонирования нужен доступ к нему. В главном окне выберите функцию и нажмите «Открыть». Группы, предметы и тесты выбираются из исходных данных. Для посещаемости укажите первое и последнее занятие. «Отмена» возвращает в меню; «Выход» завершает программу. Результат показывается в окне с прокруткой и одновременно выводится в терминал.

По умолчанию используется включённая в проект база `data/labfiles-3-26`. Путь к другой базе задаётся явно:

```bash
./bin/student-gui --data "/путь/к/labfiles-3-26"
```

В проект включена исходная база преподавателя из архива ЛР № 3, без индивидуальных исправлений из выполненной работы. Программа читает файлы и не меняет их.

## Командный интерфейс

Командный режим выполняет те же расчёты без графической сессии. Параметр `--data` при необходимости указывается перед командой.

```bash
# Списки допустимых параметров
./bin/student-report groups
./bin/student-report subjects
./bin/student-report tests 'Пересдачеведение'

# Посещаемость с 4-го по 10-е занятие включительно
./bin/student-report attendance 'Ae-21-23' 'Цирковое_Дело' 4 10

# Максимум пересдач первого теста в выбранной группе
./bin/student-report retakes 'Ae-21-23' 'Цирковое_Дело' 1

# Все четыре теста предмета с первой попытки
./bin/student-report first-pass 'Пересдачеведение'

# Самые длинные фамилии во всей базе
./bin/student-report longest-names

# Лучший результат первого теста за каждый год
./bin/student-report yearly-best 'Пересдачеведение' 1
```

Группа задаётся полным обозначением из базы, например `Ae-21-23`. Совпадающие идентификаторы студентов в разных группах не объединяются. В исходных файлах вместо полного ФИО хранятся записи наподобие `YemelyanovD`; отчёты сохраняют именно их.

Успешный отчёт поступает в стандартный поток вывода, ошибки — в стандартный поток ошибок с ненулевым кодом завершения. Отсутствие подходящих студентов отображается отдельным сообщением. Отдельной кнопки сохранения файла нет; при необходимости доступно обычное перенаправление shell:

```bash
./bin/student-report longest-names > result.txt
```
