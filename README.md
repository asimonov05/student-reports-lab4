# Анализ данных студентов

Лабораторная работа № 4: пять отчётов о посещаемости и результатах тестов на данных файловой системы преподавателя из ЛР № 3. Расчёты написаны на Bash и GNU awk; программа работает через командный интерфейс.

## Установка и запуск

Нужны Bash 4 или новее, GNU awk (`gawk`) и локаль UTF-8.

Установите зависимости для своей системы:

**Debian / Ubuntu:**

```bash
sudo apt update
sudo apt install git bash gawk
```

**Arch Linux / Manjaro:**

```bash
sudo pacman -Syu git bash gawk
```

**Fedora:**

```bash
sudo dnf install git bash gawk
```

**openSUSE:**

```bash
sudo zypper install git bash gawk
```

На других дистрибутивах установите те же пакеты через свой пакетный менеджер.

**macOS:** для командного режима установите [Homebrew](https://brew.sh/), затем выполните:

```bash
brew install git bash gawk
export PATH="$(brew --prefix)/bin:$PATH"
hash -r
bash --version
```

Встроенный в macOS `/bin/bash` обычно версии 3.2 и не подходит; версия в последней команде должна быть не ниже 4. Добавьте строку `export PATH="$(brew --prefix)/bin:$PATH"` в `~/.zprofile`, чтобы путь сохранялся для новых окон стандартной оболочки zsh. Эти инструкции пока не проверены на macOS. Для демонстрации по требованиям задания используйте Linux.

После установки зависимостей клонируйте проект и перейдите в каталог:

```bash
git clone https://github.com/asimonov05/student-reports-lab4.git
cd student-reports-lab4
```

Репозиторий закрытый: для клонирования нужен доступ к нему. Для запуска попробуйте `./bin/student-report groups`.

По умолчанию используется включённая в проект база `data/labfiles-3-26`. Путь к другой базе задаётся явно:

```bash
./bin/student-report --data "/путь/к/labfiles-3-26" groups
```

В проект включена исходная база преподавателя из архива ЛР № 3, без индивидуальных исправлений из выполненной работы. Программа читает файлы и не меняет их.

## Командный интерфейс

Параметр `--data` при необходимости указывается перед командой.

```bash
# Списки допустимых параметров
./bin/student-report groups
./bin/student-report subjects
./bin/student-report tests 'Пересдачеведение'

# Посещаемость с 4-го по 10-е занятие включительно
./bin/student-report attendance 'Ae-21-23' 'Цирковое_Дело' 4 10

# Максимум пересдач первого теста в выбранной группе
./bin/student-report retakes 'Ae-21-23' 'Цирковое_Дело' 1

# Все четыре теста предмета с первой попытки
./bin/student-report first-pass 'Пересдачеведение'

# Самые длинные фамилии во всей базе
./bin/student-report longest-names

# Лучший результат первого теста за каждый год
./bin/student-report yearly-best 'Пересдачеведение' 1
```

Группа задаётся полным обозначением из базы, например `Ae-21-23`. Совпадающие идентификаторы студентов в разных группах не объединяются. В исходных файлах вместо полного ФИО хранятся записи наподобие `YemelyanovD`; отчёты сохраняют именно их.

Успешный отчёт поступает в стандартный поток вывода, ошибки — в стандартный поток ошибок с ненулевым кодом завершения. Отсутствие подходящих студентов отображается отдельным сообщением. Для сохранения файла доступно обычное перенаправление shell:

```bash
./bin/student-report longest-names > result.txt
```

## Проверка и документация

В `bin/` лежат скрипты запуска, в `lib/` — общий код отчётов; исходная база находится в `data/`, документация — в `docs/`. Каталог `tests/` оставлен для автоматических проверок и новых тестовых сценариев. Сейчас в нём уже есть проверки вычислений и создание небольшой тестовой базы. Новые сценарии можно добавлять туда по мере работы.

Запуск существующих проверок из корня проекта (нужны Bash 4+ и gawk):

```bash
bash tests/test.sh
```
